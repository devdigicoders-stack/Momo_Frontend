# Momos Bhandar - Frontend

Restaurant Management & Business Control System (Phase 1)

## Tech Stack
- React.js & Vite
- Tailwind CSS
- React Router DOM
- Axios & Lucide React

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

App runs on: `http://localhost:5173`
Connects to backend on: `http://localhost:5000/api`
